# 例行任务提示词模板

配合第 4 章使用。例行任务里只写四件事：什么时候跑、用哪个技能、交到哪、碰到意外怎么办。做法本身写进技能，不写在这里。

用之前先确认三件事：

1. 技能已经存好，检查单九条都打了勾。
2. 5 条小样试跑全部合格，其中至少 2 条是「不该做」的情况。
3. 频率先定低。每天一次跑稳了，再考虑往上调；每次运行都要花额度。

花括号里的内容换成你自己的，其余照抄或按需删改。

---

## 1. 每日资讯盯盘

```markdown
## 每日资讯盯盘

每个工作日早上 {时间}（{时区}），按「{技能名}」技能，找过去 24 小时新发的 3 到 5 条政策新闻，写进候选表。

- 来源：只用政府官网和官方通讯社，转载稿追到原发，追不到就不收。
- 交付：候选表写好就停，在这个对话里发一句话摘要和表的位置。
- 禁区：不发帖，不联系任何人，不改候选表以外的文件。
- 没有新政策：写「今天没有符合条件的新政策」，不拿旧新闻凑。
- 来源打不开：报告是哪个来源打不开，不用昨天的数据。
```

## 2. 静默抓取，晚上一次汇总

白天只抓不报，晚上把当天的新东西合成一条发给你。适合不急、但每天都要看的信息。

```markdown
## 静默抓取

每个工作日 {时间}（{时区}），按「{技能名}」技能抓取 {来源}，结果写进 {文件夹}/{日期}.json。

- 交付：只写文件，不发消息。
- 出错：抓取失败时才发一句话，说明是哪个来源、什么错误。
- 禁区：不发帖，不联系任何人，不改这个文件夹以外的文件。
```

```markdown
## 晚间汇总

每个工作日 {时间}（{时区}），读 {文件夹} 里今天新写的文件，合成一条消息发给我。

- 格式：每条一行，写清是什么、出处、为什么值得看。
- 没有新内容：什么都不发。
- 禁区：只汇总，不发帖，不联系任何人。
```

## 3. 每周复盘

```markdown
## 每周复盘

每周{星期几} {时间}（{时区}），翻这一周 {文件夹或运行记录} 里的产出，分三类：用上了、返工了、没人看。

- 交付：一张表，每类列出条目和一句原因；末尾写一条下周要改的规则，以及它改的是哪个技能的哪一句。
- 禁区：只提建议，不自己改技能，不改例行任务。
- 没有产出：写「本周没有产出」，并检查例行任务是否停了。
```

---

## 开了以后

- 新建的例行任务要等到下一个预定时间才第一次跑。想当场看效果，用测试功能；测试会真实执行一遍。
- 前 3 天每天看一次运行记录。运行记录只留最近 20 条，早期出的问题过一阵就翻不到了。
- 遇到没想到的情况，先加进小样，改技能，5 条从头再试一遍，再回来动例行任务。
