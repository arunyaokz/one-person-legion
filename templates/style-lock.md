# 风格锁与视听核对表

配合第 11 章使用。批量出图或做短视频前先填风格锁；成片前按口播词逐句核对画面。

## 一、风格锁（出图前填写，同一批镜头共用）

| 字段 | 内容 |
|---|---|
| 项目 / 成片名称 | {名称} |
| 画幅 | {如 9:16，1080×1920} |
| 主色 / 辅助色 | {色板；色温是否统一} |
| 材质与镜头语言 | {如：中近景实物 / 等轴测三维 / 矢量扁平；同片只选一种} |
| 字体与屏幕大字 | {字体、字号上限、每行字数、是否加底框} |
| 视觉隐喻约定 | {如：书桌=拍板的人；流水线=Bot；箱子=稿件} |
| 禁用元素 | {真人脸、第三方 logo、国旗、伪造现场感、多余水印等} |
| 负向排除词 | {卡通变形、多余手指、虚焦、非现实反光等} |
| AI 标注方式 | {角标文案位置；片尾说明是否需要} |
| 规划态画法 | {虚线 / 灰显 /「规划中」大字；不得画成已建成} |

同一条视频的各分镜只替换主体描述，不改风格锁其余字段。

## 二、口播词 → 画面元素核对

按口播分段逐行填写；任一行对不上，该镜头重做或改口播，不能带病进成片。

| 口播分段 | 核心名词 | 画面实物 / 图表 | 状态（现状 / 规划 / 抽象数据） | 安全区内？ | AI 已标注？ | 是否通过 |
|---|---|---|---|---|---|---|
| {口播原文片段} | {名词} | {画面上可见的东西} | {现状实线 / 规划虚线灰显 / 数据大字} | {是 / 否} | {是 / 否 / 非 AI} | {是 / 否} |

## 三、发布前视觉检查（短视频）

- [ ] 竖屏画幅正确；关键信息在安全区内，不被平台控件挡住
- [ ] 口播提到的名词，画面上都能被眼睛抓到
- [ ] 「规划中 / 未建成 / 拟议」未画成已建成现状
- [ ] AI 生成图或视频有可见标注
- [ ] 本片各镜头共用同一份风格锁，色调与材质未跳戏
- [ ] 字幕、屏幕大字与口播一致；事实数字与正文同源

全部打勾才算过。任一项未勾，停在成片前，不进入发布批准流程。
